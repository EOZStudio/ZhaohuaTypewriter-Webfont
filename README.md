# ZhaohuaTypewriter-Webfont
本專案為朝華打字機（ZhaoHua Typewriter）的非官方woff2版，提供jsDelivr網址以便嵌入進CSS。

原作者：特里王（Terry Wang）
```
***朝華打字機***
@font-face {
  font-family: "Zhaohua-Typewriter";
  font-display: swap;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/ZhaohuaTypewriter-Webfont@v1.0.0/朝華打字機.woff2") format("woff2");
}

***迫真打字油印體***
@font-face {
  font-family: "Pozhen-Typewriter";
  font-display: swap;
  font-style: normal;
  font-weight: 400;
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/GenSekiGothic-Webfont@v1.0.0/迫真打字油印體.woff2") format("woff2");
}

***油茶饊子體***
@font-face {
  font-family: "Youcha-Sanzi";
  font-display: swap;
  font-style: normal;
  font-weight: 500;
  src: url("https://cdn.jsdelivr.net/gh/EOZStudio/GenSekiGothic-Webfont@v1.0.0/油茶饊子體.woff2") format("woff2");
}
